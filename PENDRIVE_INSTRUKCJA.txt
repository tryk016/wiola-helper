CO ROBISZ TY (Patryk):

 0. Token GitHub — TYLKO jesli repo tryk016/wiola-helper jest PRYWATNE
    (publiczne repo: pomin ten krok i linijke GITHUB_TOKEN nizej):
      github.com → Settings → Developer settings → Personal access tokens
      → Fine-grained tokens → Generate new token
        - Repository access: Only select repositories → tryk016/wiola-helper
        - Repository permissions: Contents = Read-only
        - Expiration: np. 1 rok (wpisz sobie przypomnienie)
      Skopiuj token (github_pat_...).

 1. Skopiuj swoj plik:
      ZRODLO:  C:\kreisel\system\.env
      NA:      <litera pendrive>:\.env   (np. F:\.env)
    ustaw QBO_ENV=production, wyczysc realm ID i refresh tokeny obu firm
    (Wiola loguje sie swiezo), a przy prywatnym repo dopisz:
      GITHUB_TOKEN=github_pat_...

    UWAGA: ten plik zawiera PRODUCTION klucze QBO, klucz Anthropic
           i haslo MySQL. Trzymaj pendrive bezpiecznie po instalacji.

 2. Skopiuj na pendrive (obok .env) z C:\kreisel\:
      setup_wiola.cmd
      setup_wiola.ps1
      INSTRUKCJA_IT.md    (instrukcja dla informatyka)

 3. Dodatkowo na pendrive moze byc plik:
      magemar.xlsx  (opcjonalnie, mozna pominac — Wiola sciagnie z SharePoint)

CO ROBI WIOLA / INFORMATYK NA KOMPUTERZE (szczegoly: INSTRUKCJA_IT.md):

 1. Wklada pendrive.

 2. Na pendrive: prawym na setup_wiola.cmd → "Otworz".

 3. Okienko "Wybierz plik .env z pendrive" — pendrive (np. F:\)
    → .env → OK.

 4. Czarne okno — 5-10 min, sciaga kod z GitHub i Node.js.

 5. Po zakonczeniu na pulpicie pojawia sie skrot "Wiola Helper".

 6. Pendrive WYJMIJ i przekaz Patrykowi z powrotem.
    (.env zostal juz skopiowany w bezpieczne miejsce na PC.)

POTEM CODZIENNIE:

 1. Rano: pobierasz Magemar.xlsx z SharePoint → zapisujesz jako:
          C:\kreisel\magemar.xlsx

 2. Dwuklik "Wiola Helper" na pulpicie.

 3. Przeciagasz PDFy faktur Kreisla do okna programu.

 4. Klikasz "Skanuj" — program odczyta wszystkie faktury
    (pozycje, daty, kurs). NIC jeszcze nie idzie do QuickBooks.

 5. Sprawdzasz/poprawiasz w edytorze po prawej (kurs HMRC, ilosci,
    ceny PLN/szt, ewentualnie brakujace produkty). Jak czegos brakuje
    — wpisujesz nazwe, program sam zalozy produkt w QuickBooks.

 6. Klikasz "Upload do QuickBooks" — dopiero teraz faktury ida do QBO.

 7. Gotowe faktury same znikaja po chwili (sa w "Historii").

UWAGA: miedzy fakturami jest losowe opoznienie 4-10 min (zeby historia
       w QBO nie wygladala jak automat). Mozesz kliknac "Wyslij teraz"
       zeby pominac.
