# Wiola Helper

Internal accounting automation tool for **EWI Store Ltd** and **EWI Pro Insulation Systems Ltd**.

Automates the processing of supplier invoices from Kreisel (Poland) into QuickBooks Online, including:

- OCR / LLM-based PDF parsing
- HMRC monthly exchange rate lookup
- Container ATA tracking (Magemar / CMA CGM integration)
- Automatic posting of Bills (PLN) and Invoices (GBP) to two QBO companies
- PDF attachment handling

This is **not a public application**. It is operated by EWI Store Ltd staff for internal use only.
